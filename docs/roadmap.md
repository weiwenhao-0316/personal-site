## 一、愿景与定位

### 1.1 一句话定位

**haoriver.site 是一个"个人收纳库"：收纳我学过的知识、写下的内容、沉淀的理念，最终成为一个可以写进简历、经得起追问的正式软件产品。**

### 1.2 双重目标

| 目标 | 说明 | 优先级 |
|------|------|--------|
| 学习目标 | 通过做真实产品，掌握软件工程全流程（需求→设计→开发→测试→部署→运维），为实习做准备 | 主目标 |
| 产品目标 | 把网站从"学习模板"打磨成"出厂级产品"：干净、完整、有设计理念 | 自然达成 |

### 1.3 现状诊断（2026-08-25）

| 维度 | 现状 | 差距 |
|------|------|------|
| 部署运维 | 已完成自建服务器部署，经验已沉淀文档 | 缺自动化（CI/CD），缺监控 |
| 数据存储 | 仅收藏接入 MySQL，其余模块在浏览器本地 | Notes / Library / Vault 待迁移 |
| 内容 | 页面是模板骨架，内容稀薄 | 缺真实内容（笔记、作品、理念） |
| 工程化 | 代码含教学注释、.bak 文件、无测试、无规范 | 离"出厂级"有明显差距 |
| 安全 | 无鉴权，任何人可增删数据 | 个人站可暂缓，但要理解原理 |

## 二、产品路线图（做什么）

### 阶段 A：产品地基（本次新增）

**目标：先想清楚再动手，补齐正式产品的前三件套。**

- [ ] A1 产品定义：命名、Slogan、目标读者、核心场景（写进本文档）
- [ ] A2 信息架构（IA）：重新审视 7 个页面的取舍与导航结构，砍掉或合并冗余页面

> 产出：`docs/product-spec.md`（产品定义 + 信息架构 + 设计规范）

### 阶段 B：工程化清理（达到"出厂卫生标准"）

- [ ] B1 清理教学痕迹：移除 `【第3关改动】` 类学习注释，改写成面向维护者的简洁注释
- [ ] B2 删除 `*.bak` 文件、`dist.zip`，补全 `.gitignore`
- [ ] B3 后端重构：`collections_api.py` 单文件 → 分层结构（路由层 / 服务层 / 数据访问层），为后续模块建立模板
- [ ] B4 前端规范：统一 composable 命名与错误处理方式
- [ ] B5 根目录 `README.md`：项目介绍、架构图、启动方式

### 阶段 C：数据全面上云（核心功能完善）

按迁移顺序逐个打通，每个模块都是完整的学习闭环：

- [ ] C1 Notes 笔记迁移 MySQL（第二个迁移，验证"方法论可复制"）
- [ ] C2 Library 文件库迁移 MySQL
- [ ] C3 Vault 文件存储：引入服务器文件存储（学习文件上传、静态资源服务）
- [ ] C4 老数据迁移方案：浏览器本地数据 → 服务器的迁移策略

### 阶段 D：产品体验升级

- [ ] D1 首页重设计：体现个人理念与"收纳库"定位，内容真实化
- [ ] D2 博客/笔记阅读体验：Markdown 渲染、文章详情页
- [ ] D3 移动端体验优化
- [ ] D4 Projects 页面动态化，展示真实项目（含本站）

### 阶段 E：安全与运维进阶

- [ ] E1 接口鉴权（登录 + JWT）：理解原理为主，个人站可做成"主人模式"
- [ ] E2 数据备份：MySQL 定时备份脚本
- [ ] E3 CI/CD：GitHub Actions 自动构建前端 + 触发服务器更新
- [ ] E4 监控告警：站点可用性 + 服务器资源监控

## 三、学习路线图（学什么）

每个阶段对应的知识点，按"边做边讲"模式穿插：

| 阶段 | 核心知识点 |
|------|-----------|
| A 产品地基 | 需求分析、信息架构（IA）、设计系统文档化、产品思维 |
| B 工程化 | 分层架构（Controller/Service/DAO）、代码规范、重构方法、技术债概念 |
| C 数据上云 | 数据库表设计、索引、RESTful 接口设计、并发与事务初识、文件存储原理 |

## 四、协作方式：任务卡模式

每次迭代 = 一张任务卡，格式固定：

```
【任务卡 #N】标题
所属阶段：X
功能目标：一句话说明做什么
学习目标：本次掌握什么知识点
实现要点：关键设计决策（边做边讲）
完成标准：可验证的验收条件
产出物：代码 / 文档 / 部署动作
```

流程：
1. 从路线图领取任务卡（一次一张，不贪多）
2. 我先讲设计决策和原理 → 一起实现 → 按部署五步法上线
3. 完成后更新本文档进度，重要经验沉淀到记忆/文档
4. 每完成一个阶段，写一篇"阶段复盘"（面试素材）
