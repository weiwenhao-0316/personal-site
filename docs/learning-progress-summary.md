## 二、已完成的核心里程碑：网站迁移部署（8月20日-21日）

### 2.1 部署成果

成功将个人网站从 Vercel 迁移到阿里云 ECS（2核2G，Ubuntu 22.04）+ 宝塔面板，实现：
- ✅ 前端（Vue 3）通过 Nginx 提供静态服务
- ✅ 后端（FastAPI）通过 Python 项目管理器运行
- ✅ 反向代理配置（`/api` → `127.0.0.1:8000`）
- ✅ 域名解析（腾讯云 DNSPod）
- ✅ Let's Encrypt SSL 证书 + 强制 HTTPS
- ✅ 网站成功上线：`https://haoriver.site`

### 2.2 完整执行步骤（共 14 步）

1. 购买阿里云 ECS 服务器
2. 安装宝塔面板
3. 安装 LNMP 环境 + Python 项目管理器
4. Git clone 代码到服务器（`/www/wwwroot/haoriver/personal-site`）
5. 安装 Node.js 20
6. `npm install` + `npm run build` 构建前端
7. Python 项目管理器部署 FastAPI 后端（端口 8000）
8. 宝塔添加网站（纯静态，根目录指向 `frontend/dist`）
9. 配置反向代理
10. 修改 Nginx 配置支持 Vue Router history 模式（`try_files`）
11. 腾讯云 DNSPod 修改域名解析（从 Vercel 指向服务器）
12. 停掉不需要的 MySQL/PHP 释放内存
13. 申请 Let's Encrypt SSL 证书（DNS 验证方式）
14. 开启强制 HTTPS

## 三、遇到的问题与解决方案（体现真实学习过程）

| # | 问题 | 根因 | 解决方案 | 学到的知识 |
|---|------|------|---------|-----------|
| 1 | Git 克隆不知道选 HTTPS/SSH/CLI 哪个 | 不懂 Git 认证方式 | 服务器拉取用 HTTPS | Git 三种地址的区别 |
| 2 | Python 项目添加失败"指定文件不存在" | 未选择 Python 版本 | 先安装并选择 Python 版本 | 宝塔 Python 管理器依赖 |
| 3 | 服务器找不到 npm 命令 | 未安装 Node.js | 安装 Node.js 20 | 环境依赖管理 |
| 4 | 宝塔面板突然访问不了 | 忘记面板地址/端口 | 用 `bt default` 查看 | 面板地址结构（端口+安全入口） |
| 5 | 服务器 CPU 100%、内存 98%，面板卡死 | 2G 内存跑了 MySQL+PHP+Nginx+Python 太多服务 | 停掉并禁用 MySQL 和 PHP | 服务器资源管理、服务管理 |
| 6 | 误以为改 DNS 导致服务器卡 | 概念混淆 | 澄清：DNS 不影响服务器性能 | DNS 解析原理 |
| 7 | SSL 文件验证报 403 错误 | `.well-known` 目录权限问题 | 改用 DNS 验证（添加 TXT 记录） | SSL 证书验证原理 |
| 8 | 找不到 SSL 申请入口 | 点错全局 SSL 菜单 | 正确路径：网站→设置→SSL | 宝塔面板结构 |
| 9 | `cd fronted` 报错 | 目录名拼写错误 | 改为 `frontend` | 命令行的精确性 |
| 10 | git push 被拒绝 | 远程有新提交 | `git pull --rebase` 后重推 | Git 冲突处理 |
